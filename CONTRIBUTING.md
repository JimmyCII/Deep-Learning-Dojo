# Contributing / Reviewing

V1 is out for review. The fastest way to help: **just use it** for 5–10 minutes
and leave feedback.

## How to leave feedback (no GitHub account needed)

1. Click **Feedback** in the top-right of any screen.
2. Pick a star rating (optional), say what's working / what isn't.
3. Hit one of:
   - **Copy summary** → paste into Slack/Discord/email
   - **Email Jim** → opens your mail client pre-filled
   - **Open GitHub issue** → if you have an account (button appears once the repo URL is configured)

Every entry is also saved to your browser. Visit `#/feedback` to see and export
the whole batch as JSON.

## What's especially useful

- **First-impression** notes from the dashboard before you click anything.
- **Coach hints that confused you** — they're meant to be welcoming, so tell me where they're not.
- **Challenges that felt either trivial or impossible** — both are bugs.
- **Anything visually broken** at your screen width.
- **Modules where you got stuck or quit** — tell me which one and where.

## Filing issues directly

If you have a GitHub account, you can open an issue at the repo. Use these
loose labels in the title if helpful:

- `[bug]` something broken or visually wrong
- `[ux]` confusing flow / unclear copy / pacing
- `[content]` factual issue or weak explanation
- `[idea]` new feature, new lab, new challenge

## Code contributions

This is currently a one-author personal project, but pull requests are welcome
for clear bug fixes. For anything bigger, open an issue first so we can talk
through the direction.
